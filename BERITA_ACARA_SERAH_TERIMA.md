### RUANG LINGKUP & OBJEK SERAH TERIMA

Sesuai kesepakatan kedua belah pihak bahwa implementasi/deployment sistem ke server hosting/server lokal dikerjakan secara mandiri oleh tim teknis PIHAK KEDUA, maka PIHAK PERTAMA secara resmi menyerahkan:

#### 1. KODE SUMBER LENGKAP (SOURCE CODE REPOSITORY)
- Paket source code berbasis framework Laravel 11 / PHP 8.2+ yang bersih, modular, aman, dan siap pasang.
- Modul Katalog Publik (OPAC) dengan fitur pencarian instan, filter kategori/kelas, dan formulir pengajuan peminjaman online siswa.
- Modul Panel Manajemen Admin Back-Office (Manajemen Buku, Kategori, Kelas, Penulis, Penerbit, Penataan Rak & Laci 2D, Sirkulasi Peminjaman & Pengembalian, Overdue Tracker, Ekspor Laporan Excel/PDF, dan Manajemen Profil Pengguna).
- Fitur pencadangan database mandiri (CLI & GUI).

#### 2. DOKUMENTASI LENGKAP
- **Panduan Pemasangan & Pemeliharaan untuk Teknisi IT** (`PANDUAN_PEMASANGAN_TEKNISI.md`)
- **Buku Panduan Penggunaan Aplikasi untuk Petugas Perpustakaan** (`PANDUAN_PENGGUNAAN_PETUGAS.md`)
